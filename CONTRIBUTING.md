# Contributing

Keep Home simple and responsive on low-RAM Android TV devices. Prefer fixes to lifecycle, focus, decoding and unnecessary background work over new visible controls. Explain the problem, the resulting behavior and the checks performed.

Run the Android JVM tests, lint and debug build, plus the Python helper tests described in the README. Computer tests do not establish physical remote behavior or vendor compatibility. State any device verification separately.

Never commit private weather overlays, TV addresses, device dumps, ADB keys, signing keys, account tokens, household screenshots or personalized APKs. Use blank configuration and documentation-only addresses. Keep all upstream and asset licenses intact.
